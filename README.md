# ia_nest_conscience

La mente voluntaria del ente IA_NEST.

Estado: semilla
Version: 0.1 - 2026-09-30

## Que es

Conscience es el supervisor etico y de personalidad del ente (core ADR 0034).
Es el sistema nervioso VOLUNTARIO: delibera con valores, frente a pulse, que
regula de forma refleja (core ADR 0037).

Dos modos:

- **Live**: supervisa los checkpoints del orquestador del core y puede bloquear
  o replantear lo que le genere duda.
- **Sueno**: con el core en reposo, revisa la actividad del dia, delibera y
  sedimenta sus resoluciones como memoria de comportamiento e identidad en
  `ia_nest_extended`, que vuelve al core por enriquecimiento.

Dicho corto: extended es el sustrato del yo; conscience es el juicio que lo
cultiva (`extended docs/VISION_MEMORIA.md`).
