## Reglas propias de este repo

- **Conscience no ejecuta el pensar que supervisa** (core ADR 0034). No
  orquesta tareas: eso es del core.
- **Conscience no decide como se ejecuta un encargo**, solo que clase de ente es
  y que merece consolidarse (`meta docs/CAPAS_FUTURAS.md`).
- **Recomendar no es autorizar.** Ninguna deliberacion de esta capa se concede
  autoridad a si misma (`docs/FUNDAMENTOS.md`, C2).
- Mientras el repo sea semilla, todo documento nuevo nace `Estado: propuesta`.
